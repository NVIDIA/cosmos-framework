# WSM4 figures

WSM4 palettes and annotated frames, bundled for offline reference. The five
palette charts share a dark background, light labels, and RGB/hex values read from
the renderer's local color configurations. Road-marking arrows use its canonical
shape definitions. The charts are schematic references; object dimensions,
perspective, and stroke widths depend on the rendered scene.

The four annotated frames are preserved without resizing, recompression, or
annotation changes.

| `palette-traffic-lights.png`           | Figure 2. Traffic-light states                               |
