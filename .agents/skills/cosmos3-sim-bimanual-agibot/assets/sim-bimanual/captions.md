# Assets — Cosmos3-Nano-Sim-Bimanual recipe (held-out AgiBotWorld-Beta, DGX Station GB300)

All frames are from the 901-frame rollouts described in the README (checkpoint `1d95a0b5b19d49a24aceebf578cf5e85db310ac0`, 4 steps, guidance 1.0, forward dynamics, 640x352 output, 30 fps). "Real" is the AgiBotWorld-Beta head camera converted to 640x360; "matched-action rollout" replays the episode's own 29-D actions from its real first frame; "frozen first frame" holds the real frame 0 for all 901 frames (static control).

**Source data, licence and attribution.** The "real" panels and every first frame in these pictures and clips are from the dataset `agibot-world/AgiBotWorld-Beta` (AgiBot World Contributors; Hugging Face, gated), dataset revision `2252b3fdc88dc67fa5d5e4b771e1b86f5e71c278`, licensed **CC BY-NC-SA 4.0** under the "AgiBot World COMMUNITY LICENSE AGREEMENT" shown on the dataset card. The media in this folder are derivative works of that dataset (crops, frame strips and side-by-side composites with model output) and are shared under the same licence, for non-commercial use with attribution; the generated panels are synthetic and must be labelled as such before they enter any dataset. Episodes shown: 815362 (task 600) and 810449 (task 596). The recipe does not bundle or rehost any original dataset file; users download the dataset from the publisher after accepting its terms.

**Crop used for every comparison ("top 352 rows"):** the real 640x360 frame is cropped to rows 0–351 (y0 = 0, y1 = 352) and all 640 columns (x0 = 0, x1 = 640); the bottom 8 rows (352–359) are discarded. `tools/eval_fidelity.py --align auto` chose this "top" crop for all 20 matched episodes, all 20 frozen baselines and all 20 swap rollouts by frame-0 PSNR (e.g. task600_ep815362: top 35.50 dB, center 22.17 dB, bottom 19.48 dB), recorded in each `*_summary.json` as `real_crop_box`.
