## (2) Headline numbers

- **20.58 ± 0.06 dB (cell 1, iteration 1000, seeds 0/1/2)** was scored on the **DCP checkpoint**
  `runs/main/cosmos3_action_fd/action_sft/action_fd_libero_posttrain/checkpoints/iter_000001000` loaded with the run's `config.yaml`
  (`eval/iter1000*/run_config.json`: `checkpoint_path` = that directory, `use_ema_weights: true`). With a YAML config the framework loader ignores
  `use_ema_weights` and loads the **regular** `net.*` weights (`cosmos_framework/inference/inference.py:1393` passes `load_ema_to_reg` only for
  module-type configs; the YAML/HF path ends in a plain `dcp.load`, `inference/model.py:774`). The number is therefore a regular-weight result of
  the DCP checkpoint, **not** the safetensors export: `export_iter1000/` holds the EMA weights (`export_model.py`, `load_ema_to_reg=True`) and has
  not been evaluated. The same applies to every FD/ID evaluation of this recipe (correction notes dated 2026-10-06 in the run records); the
  base-model control was run with `--no-ema` (the base checkpoint has no EMA copy), so it is a regular-weight number too.
- **Base-model control PSNR.** `eval/control_base/summary.json`: whole-frame PSNR 12.8312 dB, third-person (left half) 13.1272 dB, wrist (right half)
  13.1308 dB — the README rounded both per-view values to 13.13. All three are means over the same 4,971 per-frame values. They are consistent: the
  whole-frame PSNR of a frame is 10·log10(255²/MSE_frame) with MSE_frame = (MSE_left + MSE_right)/2; recomputing it from the two halves' MSEs
  reproduces the 12.8312 exactly (max per-frame difference 7e-15 dB), while the mean of the two per-view PSNRs is 13.129. The 0.30 dB gap is the
  concavity of the logarithm (the whole-frame PSNR is dominated by the worse half of each frame), not a bookkeeping error.
- Every other number in the README tables is listed with its source record in `results/metrics.json`.
