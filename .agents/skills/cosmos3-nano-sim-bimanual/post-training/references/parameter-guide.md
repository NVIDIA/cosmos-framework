# Parameter adaptation guide

`contract-locked` changes the model or data interface. `reference-fixed`
reproduces the documented recipe. `tunable` may be adapted with validation.
`experimental` requires a separate study. `derived` is computed from other
values.

| Parameter or group                       | Reference value                                                                                                                                                       | Policy            | Adjustment guidance                                                                                                                                                        | Coupled settings                                                   | Expected effect                                                                                                            | Required validation                                                                                                                         | Failure signals                                                                                                                                                               |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Stage order                              | Representation adaptation → causal prediction → fixed-step distillation → rollout distillation                                                                        | `contract-locked` | Keep the order unchanged.                                                                                                                                                  | Checkpoint roles, attention, rollout                               | Defines the training method.                                                                                               | Verify every stage handoff.                                                                                                                 | Wrong frozen reference or incompatible keys.                                                                                                                                  |
| Cross-stage checkpoint state             | Weight-only warm start; `checkpoint.load_training_state=False` at every Stage 0–3 boundary. Stage 0 copies loaded Cosmos3-Nano regular weights into a fresh EMA tree. | `contract-locked` | Use full-state loading only for a compatible same-stage continuation. Keep the Stage 0 strict skip-and-copy procedure because the Cosmos3-Nano conversion has no EMA tree. | Optimizer, scheduler, trainer counter, RNG, dataloader cursor, EMA | Prevents state from a preceding stage entering the next stage while giving Stage 0 matched regular and EMA initialization. | Resolve every boundary config; assert its inputs, state flag, and skip lists; confirm the first Stage 0 save contains regular and EMA keys. | Nonzero inherited step, wrong LR state, stale sampler cursor, missing action-module initialization, missing Cosmos3-Nano EMA keys, or mismatched initial regular/EMA weights. |
| Action width                             | 59 semantic values padded to 64; 32 domains                                                                                                                           | `contract-locked` | Define and document a new mapping before using another schema.                                                                                                             | Masks, embeddings, checkpoint                                      | Preserves action meaning.                                                                                                  | Mapping, mask, finite-value, and checkpoint-load tests.                                                                                     | Width or domain mismatch.                                                                                                                                                     |
| Timing                                   | `T` actions for `T+1` observations; temporal compression 4                                                                                                            | `contract-locked` | Change only with a new timing contract and compatible data and checkpoint chain.                                                                                           | Frame count, latent count, packing                                 | Preserves observation/action alignment.                                                                                    | Validate the longest sample's frame and latent arithmetic.                                                                                  | Off-by-one alignment or truncation.                                                                                                                                           |
| Causal chunk                             | 2 latent frames in Stages 1–3                                                                                                                                         | `contract-locked` | Keep consistent across causal training, frozen references, and inference.                                                                                                  | Cache, frozen references, inference                                | Sets prediction granularity.                                                                                               | Train, load, and generate smoke tests.                                                                                                      | Cache-shape error or chunk discontinuity.                                                                                                                                     |
| Packed-token budget                      | 400,000 in Stage 0; 500,000 in later stages                                                                                                                           | `reference-fixed` | Reduce only after recording emitted batch and truncation behavior.                                                                                                         | Sequence length, memory                                            | Changes memory use and packing utilization.                                                                                | Run the longest-sample training step.                                                                                                       | OOM or empty pack.                                                                                                                                                            |
| Activation checkpointing                 | Full in Stages 0–1; selective in Stages 2–3                                                                                                                           | `tunable`         | Change one stage at a time.                                                                                                                                                | Memory, step time                                                  | Trades compute for activation memory.                                                                                      | Run a bounded distributed step and compare memory and time.                                                                                 | OOM or excessive slowdown.                                                                                                                                                    |
| Distributed placement                    | Recommended starting point: FSDP shard degree 8; context-parallel degree 4                                                                                            | `tunable`         | Users may choose another topology. Ensure the world size satisfies the configured parallel degrees and record the effective batch.                                         | World size, data parallelism, context parallelism, accumulation    | Changes throughput, memory use, and optimizer exposure.                                                                    | Validate the resolved layout, effective batch, collectives, and checkpoint save/readback.                                                   | Nondivisible layout, collective hang, or OOM.                                                                                                                                 |
| Stage 0/1 optimization                   | LR `1e-5`; betas `(0.9, 0.99)` / `(0.9, 0.999)`; weight decay `0.05` / `0.01`                                                                                         | `reference-fixed` | Treat changes as a new optimization study.                                                                                                                                 | Batch, scheduler                                                   | Changes stability and convergence.                                                                                         | Compare loss and gradient traces.                                                                                                           | Divergence or spikes.                                                                                                                                                         |
| Stage 2 optimization                     | LR `2e-6`; betas `(0, 0.999)`; weight decay `0.01`; flow loss scale 100                                                                                               | `reference-fixed` | Preserve for recipe comparisons.                                                                                                                                           | Frozen reference, global batch                                     | Controls fixed-step distillation.                                                                                          | Verify trainable/frozen weight loading and finite loss.                                                                                     | Collapse or non-finite loss.                                                                                                                                                  |
| Stage 2 schedule                         | 48 steps, skip 1, guidance 3, shift-5 four-step SDE                                                                                                                   | `contract-locked` | Keep the schedule as one coupled unit.                                                                                                                                     | Inference schedule                                                 | Defines the distillation target.                                                                                           | Assert the resolved schedule and run generation.                                                                                            | Timestep mismatch.                                                                                                                                                            |
| Stage 3 rollout                          | `[4]`, one matching shift-5 SDE schedule, maximum mode, block 1                                                                                                       | `contract-locked` | Keep the rollout and saved student schedule aligned.                                                                                                                       | Inference, frozen references                                       | Defines rollout training.                                                                                                  | Verify the schedule, phase-level losses, and generation.                                                                                    | Replay error, schedule mismatch, or drift.                                                                                                                                    |
| Stage 3 optimization                     | Student LR `1e-6`; critic LR `2e-7`; betas `(0, 0.999)`; weight decay `0.01`. Iterations divisible by 6 update the student; the other five update the critic.         | `reference-fixed` | Preserve the one-plus-five cadence.                                                                                                                                        | Update cadence 6                                                   | Balances the two phases.                                                                                                   | Over iterations `0..11`, require two student and ten critic updates with separate loss and gradient traces.                                 | One phase dominates or phase counters differ from `2/10`.                                                                                                                     |
| Iterations / save cadence                | 35k, 8k, 4k, 1.5k for Stages 0–3; save every 100                                                                                                                      | `reference-fixed` | Use shorter runs for workflow checks; use the reference budgets for recipe reproduction.                                                                                   | Artifact iteration                                                 | Controls training exposure and handoff availability.                                                                       | Stop and read back a saved checkpoint.                                                                                                      | Missing handoff checkpoint.                                                                                                                                                   |
| Learning-rate scaling after batch change | Retain the stage LR initially                                                                                                                                         | `tunable`         | Preserve LR when first adapting placement. If the effective batch changes, compare one explicit LR change at a time.                                                       | Emitted batch, accumulation, optimizer, scheduler                  | Controls stability when optimizer exposure changes.                                                                        | Record batch arithmetic and compare finite loss and gradient traces.                                                                        | Loss discontinuity, spikes, or divergence.                                                                                                                                    |
| Global batch                             | Derived from emitted samples, data-parallel world size, and accumulation                                                                                              | `derived`         | Recompute after placement, packing, or accumulation changes.                                                                                                               | Placement, packing                                                 | Sets optimizer exposure.                                                                                                   | Log the resolved effective batch.                                                                                                           | Double-counted parallelism.                                                                                                                                                   |
