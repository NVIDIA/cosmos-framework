# Cookbook notebooks → agent skills: migration records

One section per migrated cookbook. Each records, cell by cell, where the notebook content went (`SKILL.md`, a
`references/` file, or not migrated with the reason), the audit results, and the public permalink of the retired
notebooks. Add a new section when another cookbook is folded into a skill.

## cosmos3-generate-media ← `cookbooks/cosmos3/generator/audiovisual` (2026-10-20)

The seven inference notebooks and the README of the `cookbooks/cosmos3/generator/audiovisual` cookbook were migrated
**verbatim** into `.agents/skills/cosmos3-generate-media/references/` (one file per backend plus a shared `payloads.md`) and then removed from this
repository. The notebooks remain readable at the pinned public commit:

Rules applied: every command, flag, value, note and explanation was kept as written (nothing was corrected, even where
evaluation runs later found a statement wrong — those corrections are a separate, reviewed step); only Jupyter plumbing was
dropped (magics, kernel registration, display helpers, path discovery); notebook asset paths were translated to the skill's
`assets/`; the repeated per-use-case create/run/view cells were collapsed into one table per backend. Each file was audited
twice against its sources by an independent reader; the final audit result is recorded below.
